EasyTax — wireframes v1

Low-fidelity. Real UI uses stock WinUI 3 controls (NavigationView, AutoSuggestBox, NumberBox, ToggleSwitch, ToggleButton, Expander, Segmented) plus LiveCharts2 for charts and gauges. Dark/light follows the system theme.

1 · Dashboard

The top bar is shared by Dashboard and Client page: client picker with prev/next, year, month strip (green = accounted, orange = not, grey = before the client joined) and an "Accounted" toggle for the selected month.
