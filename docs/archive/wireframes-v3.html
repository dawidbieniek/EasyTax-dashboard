2 · Client page

Same app bar as the dashboard minus year/month and the Accounted toggle (those are month-scoped), so client switching behaves identically. Header card shows photo, name, contact line and chips; the Edit button turns the tab forms editable, with Save/Cancel replacing it.

Width handling: the tab content sits in a container with MaxWidth ≈ 880, left-aligned under the header (so the form lines up with the header instead of floating in the middle). Fields are laid out in a 2-column grid; below ~700 px the grid collapses to 1 column via an AdaptiveTrigger (WinUI has no CSS-style breakpoints, but visual states with MinWindowWidth do the same job). On very wide windows the extra space on the right stays empty — or we can use it for a "Summary" side card (see right-hand note).
