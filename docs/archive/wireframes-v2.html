EasyTax — wireframes v2 · dark

Several options per screen, so we can pick or mix. Client avatar = WinUI PersonPicture (photo if set, otherwise initials like “JK”). Left rail is a collapsed NavigationView (icons only, expands on hover/click). Top bar content is shared by Dashboard and Client page.
